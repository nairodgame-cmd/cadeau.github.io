💡 Comment fonctionne la sauvegarde ?

1. Sur votre téléphone/ordinateur : chaque cadeau ajouté est sauvegardé instantanément dans la mémoire de votre navigateur (localStorage).

2. Pour partager votre liste à jour avec vos proches sur GitHub Pages : cliquez sur le bouton ci-dessous. Il génère un nouveau fichier index.html contenant tous vos nouveaux cadeaux intégrés en dur dans le code ! Il vous suffit de remplacer le fichier sur votre dépôt GitHub.

Rappel : Mettre en ligne sur GitHub en 2 minutes

  1. Créez un dépôt public sur github.com (ex: mes-cadeaux).
  2. Déposez-y ce fichier renommé en index.html (via Add file > Upload files).
  3. Allez dans Settings > Pages, choisissez la branche main et cliquez sur Save. Votre site est en ligne !
